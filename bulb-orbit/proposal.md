# WeDream AI 首页改版需求文档（proposal.md）

> 版本：v1.0 ｜ 日期：2026-07-12 ｜ 状态：待用户审阅
> 基底：GitHub [`wei500L/yun`](https://github.com/wei500L/yun)（Vite + three.js 0.160 + GSAP 粒子灯泡首页）
> 本文档经互动式提问逐项确认后生成；所有「已确认」标记均为用户拍板结论。
> 注意：与平台权威需求文档 `doc/proposal.md` 无关，本文件只覆盖**首页（落地页）改版**这一件事。

## 一、背景与目标

- 旧版首页原型 `bulb-orbit/index.html`（单文件、两段式点亮门控、24 家模型芯片）**现阶段废弃**，仅留档参考。
- 新首页**以 yun 页面为基底**（其配色、轨道能量线、卫星形态、HUD 联动、鼠标流体排斥等全部保留），在其上叠加下述改造。
- 从旧版继承两点：**灯泡的大小观感**、**轨道上模型的数目与种类（24 家）**；旧版的轨道颜色与中心配色不再使用，一律以 yun 为准。

### 改造四要点（用户原始需求）

| # | 需求 | 落地方式（本文档章节） |
| --- | --- | --- |
| 1 | 页面横向 2:2:1 三栏：左品牌介绍、中灯泡、右信息栏 | §三 |
| 2 | 灯泡放大（对齐旧版观感）、保留底座；模型增至旧版 24 家；点击模型灯泡变色；右栏展示各供应商模型特点与场景 | §四 §五 §六 |
| 3 | 轨道自身也围绕灯泡旋转（不只是模型沿轨道运动） | §五 |
| 4 | 灯泡更圆润、一体化（消除现有棱角） | §四 |

## 二、已确认决策清单

| 决策点 | 结论 |

yun 原样毛玻璃单卡：状态点 + 模型系列名 + 供应商 + 描述 + 遥测行；左边框颜色随当前供应商品牌色。默认态显示「WeDream 核心」自述（文案见附录 A 第 0 条）。**全部中文**（W5）。

## 四、灯泡（核心视觉）

| 项 | 规格 |
| --- | --- |
| 大小 | 放大至**旧版观感**：灯泡+底座整体约占视口高度 **55–60%**（yun 现状约 35%）。轨道半径、相机距离等比联动调整 |
| 圆润化 | 从 yun 仓库取 `dengpao.glb`（83MB，一次性下载），**网格细分 + 平滑**后重采样 **40000 粒子 +法线** 生成新 `dengpao_points_smooth.bin` 替换现有数据。保留螺纹、底座小丘等原造型，只消除面片棱角，达到「圆润一体化」 |
| 结构保留 | 玻璃罩（穹顶+颈部）、体积辉光 Sprite、金属灯座、**发光底座**全部保留（yun 原样） |
| 配色 | yun 青色生物发光系（核心 `#00f0ff`、粒子白蓝→青蓝渐变）；**不用**旧版配色 |
| 动效保留 | 粒子呼吸/闪烁/微噪、整体慢自旋、**鼠标靠近流体排斥**（粒子被推开成环、离开回流） |
| 变色 | 点击卫星时核心变品牌色，见 §六 |

> 平滑重采样脚本放 `tools/`，参考 yun 仓库 `extract_dengpao.cjs`；若细分平滑效果不理想，备选方案为程序化理想灯泡点云（已确认为 fallback，不作首选）。

## 五、轨道与卫星

### 5.1 轨道（2 条椭圆能量线）

- yun 的能量线效果**全部保留**：核心细线+柔光双层、彗尾流光（卫星走过处发亮拖尾）、能量流动、近亮远暗深度渐隐、灯泡剪影遮罩（远侧弧线不横穿灯泡）。
- 两条轨道倾角不同、转向相反（yun 原样），半径随灯泡放大**等比外扩**，保持「轨道约 2.8×/3.6× 灯泡宽」的原比例关系。
- **【新增】轨道整体进动**：每条轨道组（含线与卫星）绕场景竖轴整体慢速旋转——轨道 A 顺时针、轨道 B 逆时针，周期不同（初值 A≈45s/圈、B≈70s/圈，实施时按观感调）。效果：椭圆轨道的朝向持续变化，实现「轨道也围绕灯泡运动」；卫星沿轨道的运行与彗尾照常，两种运动叠加。
- 进动速度与卫星运行速度错开，避免视觉合拍；`prefers-reduced-motion` 时进动减速或停。

### 5.2 卫星（24 颗）

| 轨道 | 成员（12 颗/条，交错排布避免同类相邻） |
| --- | --- |
| 国际轨 | OpenAI、Anthropic、Gemini、Meta、Mistral、DeepSeek、xAI、Cohere、Midjourney、Stability AI、Hugging Face、Perplexity |
| 国产轨 | 通义千问、MiniMax、豆包、阶跃星辰、Kimi、华为盘古、百度文心、零一万物、腾讯混元、百川智能、智谱 GLM、讯飞星火 |

- 卫星结构 yun 原样三层：品牌色光晕背衬 + 细金属环&玻璃圆盘 + **高清品牌 logo 贴图**（始终面向相机的 billboard，近大远小、远侧降透明但保持可辨）。
- **logo 素材**：国产 12 家用现有 `logos/*.png`；国际 12 家由旧版内嵌 SVG 栅格化为 512px 透明 PNG（或取 lobehub 图标包，与国产同源）。**全部 24 张过 yun 的 `process_logos.cjs` 处理管线**（含 inverse-ACES 显示补偿，保证 bloom 调色下品牌色还原）。
- **粒子 halo**：yun 已有 7 家可复用（OpenAI/Anthropic/Gemini/通义/豆包/智谱/xAI-Grok）；其余 17 家首期用品牌色光晕替代（观感一致），后续可补采样 bin，不阻塞上线。
- 24 家品牌色总表见附录 B（点击变色与 HUD 边框共用）。

| 交互 | 行为（yun 机制，扩展到 24 家） |

## 九、工程与部署

### 9.1 工程形态（已确认：Vite）

```
bulb-orbit/
├── proposal.md            ← 本文档
├── index.html 等旧版文件    ← 废弃留档，不再改动
└── v2/                    ← 新 Vite 工程（以 yun 源码为底）
    ├── index.html
    ├── package.json       （three@0.160、gsap、vite）
    ├── src/main.js        （场景/轨道/卫星/联动）
    ├── src/style.css      （2:2:1 布局、中文字体栈）
    ├── public/models/     （dengpao_points_smooth.bin + 7 家 halo bin）
    ├── public/logos/      （24 张处理后的品牌 PNG）
    └── tools/             （glb 平滑重采样、logo 处理脚本）
```

- 字体：**去掉 Google Fonts 外链**（国内访问不稳），中文用系统字体栈（`PingFang SC / Microsoft YaHei / …`），品牌标题可自托管一款拉丁字体或直接系统栈。
- Mac 上 `npm i && npm run dev` 调试（独立小工程，不碰平台 `web/` 的依赖坑）；`npm run build` 出 `dist/` 纯静态产物。

### 9.2 部署与平台接入（W4：部署在服务器）

1. `dist/` rsync 至服务器，nginx 在 `*.wedreamhub.com` server 块加静态 `location /landing/ { alias …; }`（优先级在反代之前，细节循 `doc/deployment.md`）。
2. 管理后台「系统设置 → 首页内容」填 `https://www.wedreamhub.com/landing/` → 平台首页以 **iframe 全屏**嵌入本页，**顶部导航保持 newapi 原生**。
3. iframe sandbox 现状无 `allow-top-navigation`，CTA 默认 `target="_blank"` 新标签打开；**推荐顺手改一行** `web/default/src/features/home/index.tsx` 的 sandbox 加 `allow-top-navigation-by-user-activation`，使「立即开始」同页跳转（属平台前端小改，随下次平台构建部署）。
4. 同域名部署，无跨域/混合内容问题。

## 十、性能与兜底

- 24 颗卫星（vs yun 11 颗）：raycast 与 draw call 增加有限；halo 点云仅 7 家（其余光晕替代），总粒子预算与 yun 同量级。
- 目标：桌面 1080p ≥50fps；移动端降级后 ≥30fps。
- **WebGL 不可用**：显示静态海报图（上线后实截一张 2:2:1 全景 PNG 作兜底背景）+ 左栏文案照常（纯 DOM）。
- `prefers-reduced-motion`：入场动画直接呈现终值，进动/呼吸减弱。
- 验证纪律遵守 **W6**：playwright/无头浏览器/本地 server 用完即关，`ps` 复核零残留。

## 十一、验收标准（DoD）

1. 桌面 1920×1080：三栏 2:2:1；灯泡+底座占屏高 ≥55%；24 颗卫星 logo 全部可辨；轨道进动肉眼可见（≤70s/圈）。
2. hover 任一卫星：右栏 ≤0.5s 完成切换为该供应商中文卡片（yun 原生 0.15s 淡出 + 0.35s 淡入），边框变品牌色。
3. 点击任一卫星：灯泡核心 0.5s 内渐变为品牌色；移开 1s 后回落青色。
4. 灯泡剪影平滑无面片棱角（对比旧截图）。
5. 界面文字全中文（品牌与供应商英文名除外）。
6. 移动端 390×844：竖排可读、无横向滚动、点卫星可切 HUD。
7. WebGL 禁用时兜底海报正常显示。
8. 经平台首页 iframe 实测：原生导航在顶、页面全屏、CTA 可跳转。
9. Chrome/Safari 最新版控制台零报错；验证进程零残留（W6）。
