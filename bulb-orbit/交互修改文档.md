## 二、交互状态机

```
加载
 └─► body.pre（蓄势态）
       · 只亮灯泡 + 光晕呼吸 + 底部「点 击 点 亮」提示轻微明暗呼吸
       · 整页 cursor:pointer，logo 芯片 pointer-events:none（不可误触）
       │
       │  触发器（三选一，均只生效一次）：
       │    ① 鼠标/触屏 pointerdown（页面任意位置，含灯泡）
       │    ② 键盘 Enter
       │    ③ 键盘 空格
       ▼
 body.lit（点亮态）＝ 最终常驻态
       · 提示文字淡出
       · 全景元素按下方时间轴渐现，之后回到原有常驻动效（呼吸/流光/自旋/漂移）
```

**直达终态入口**（截图 / 演示 / 分享用，跳过交互）：打开 `index.html#final`（`#lit`、`?state=final` 亦可）。实现为 `<body>` 起始处的一段内联脚本，在首帧渲染前把 body 类换成 `lit`。

## 四、点亮时间轴（t=0 为点击瞬间）

| t（秒） | 元素 | 效果 |
| --- | --- | --- |
| `t=0` | 3D 核心喷发 | 灯丝 scale 1→1.8→1、辉光 0.28→0.55→0.28、点光 1.5→2.8→1.5，0.7s 正弦包络 |
| 0 → 0.5 | `#hint` | 淡出并 visibility:hidden |
| 0.10 → 1.70 | `#bg`、`#grid` | opacity 0→1 |
| 0.12 → 1.62 | `#orbits` 轨道光带 | opacity 0→1 |
| 0.15 / 0.30 / 0.45 / 0.62 | 徽章 / `Wedream AI` / 让灵感不再受限 / 副标题 | 各自 0.9s `rise`（上移 16px + 淡入），与轨道**同时**开始 |
| 0 → ~2.0 | 24 个 `.chip` | 第 i 个于 `i×0.055s` 开始，0.75s easeOutCubic：透明度 0→1、尺寸 55%→100%（叠乘原景深缩放）；顺序 = 国际轨道 12 个 → 国产轨道 12 个，呈「沿轨道扫过点亮」 |
| 0.35 → 1.35 | `.fp` 流光 | 透明度乘子 0→1 |
| 0.55 → 1.95 | `.ring` 雷达圈 | opacity 0→1 |
| 0.70 / 0.95 | `.ray` 光线 / `.p` 星尘 | 解除隐藏并入常驻动效 |
| ~2.1 | — | 全部就位，进入常驻最终态（即阶段二截图） |

## 六、代码改动明细（均在 `index.html`）

### 1. CSS

- **`.rise` 由「加载即播」改为「点亮才播」**：
  ```css
  .rise { opacity:0; transform:translateY(16px); }
  body.lit .rise { animation:rise .9s cubic-bezier(.22,.7,.25,1) var(--rd,0s) forwards; }
  ```
- **新增两段式状态块**（`pre` 隐藏清单 + `lit` 渐显过渡，见上文时间轴数值）；粒子/光线因 opacity 被各自 keyframes 占用，改用 `visibility` + 延迟解除的方式并入。
- **新增 `igniteBurst`**：`body.lit #halo` 先播一次迸发（1.15s）再无缝接回 `breathe` 呼吸——**2026-07-07 起仅在 WebGL 不可用回退态生效**（默认 `webgl3d` 路径下 `#halo` 已隐藏，点亮迸发由 3D 核心喷发承担，0.7s，见 §四/§十）。
- **新增 `#hint` 样式** 与 `hintPulse` 呼吸；`body.lit #hint` 淡出。
- **`prefers-reduced-motion`**：`rise` 直接呈现终值、迸发/呼吸/提示动画全部禁用（原有规则同步扩展了 `#hint` 与 `body.lit #halo`）。

### 2. HTML

- `<body>` → `<body class="pre">`，并紧跟一段内联脚本：URL 带 `#final`/`#lit`/`?state=final` 时首帧直接置为 `lit`。
- 主标题：`<span class="hl1 rise">Wedream AI</span>`。
- `#vignette` 后新增 `<div id="hint" aria-hidden="true">点 击 点 亮</div>`。

### 3. JS（IIFE 内）

- **状态与触发**（置于常量区之后）：
  ```js
  let revealT0 = body.classList.contains('lit') ? -1e9 : Infinity; // 点亮时刻（秒）
  function ignite() { …remove('pre'); add('lit'); revealT0 = performance.now()/1000; }
  addEventListener('pointerdown', ignite);
  addEventListener('keydown', e => { if (e.key === 'Enter' || e.key === ' ') ignite(); });
  ```
- **芯片逐个浮现**：`chips.push(… , idx: chips.length)` 记录序号；`frame()` 内每帧计算
  `cr = easeOut3(clamp01((t - revealT0 - idx*0.055) / 0.75))`，把 `cr` 乘进原有景深透明度、`0.55+0.45*cr` 乘进原有景深缩放。点亮前 `revealT0=Infinity` ⇒ `cr=0`（全隐）；直达终态 `revealT0=-1e9` ⇒ `cr=1`。
- **流光汇入**：同理乘 `fr = easeOut3(clamp01((tr-0.35)/1.0))`。

> 设计要点：芯片与流光的透明度本就由 JS 每帧写入（内联样式），CSS 类无法直接盖过，故采用「全局点亮时刻 `revealT0` + 每帧乘法因子」实现渐现；静态元素（背景/轨道/文字/雷达圈）则用纯 CSS 类切换 + transition，两套机制共享同一起点。

## 八、可访问性与降级

- 键盘可触发（Enter / 空格），与鼠标/触屏等效。
- `prefers-reduced-motion: reduce`：点击后文字直接呈现、无迸发/呼吸/提示闪烁；渐现过渡保留（纯透明度变化）。
- 不点击则永远停留在阶段一；`#final` 入口可跳过交互直达终态（亦是嵌入他页时的「静态海报模式」）。
- 若不要「点 击 点 亮」提示：删除 `#hint` 那一行 HTML 即可（相关 CSS 可留，无副作用）。
