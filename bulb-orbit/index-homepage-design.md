# WeDream AI 首页改造设计（index.html · 滚动式落地页）

> 版本：v2.0 ｜ 日期：2026-07-12 ｜ 状态：待用户定稿
> 目标文件：`bulb-orbit/index.html`（2MB 单文件，three.js + 点云 base64 内联）
> 本 spec 经互动式提问逐项确认后生成；所有「已确认」均为用户拍板结论。
> v2.0 相对 v1.0 的变化：由**单屏 16:9 Hero** 升级为**可向下滚动的完整首页**（Hero + 3 个内容板块）。

---

## 一、目标与背景

- 把现有 `index.html`（当前：居中单屏 + 两段式「点击点亮」+ 24 家卫星）重构成一个**可向下滚动的完整首页**：
  - **首屏 Hero** = 2:2:1 灯泡场景（占满第一屏 ~100vh）；
  - 往下滚依次是 **① 创作搭档 → ② 我们的优势 → ③ 套餐价格** 三个内容板块。
- **定位**：这是 WeDream AI（newapi 平台）的首页，**以 iframe 内嵌**平台，顶部导航/页脚由平台 newapi 原生承担，本页只做内容。
- **与 proposal.md / v2 的关系**：proposal 曾判定老 index.html 废弃、另建 `v2/`。**用户本次改为直接在 `index.html` 上改造**并扩成滚动首页。本 spec 就此范围**取代** proposal 的"另建 v2"与"单屏"设定；proposal/v2 的视觉目标（2:2:1、灯泡、动态 HUD、24 家、点击变色、轨道进动）作为设计参考被继承。**本次不动 `v2/`。**
- **不碰**文件内两大块 base64（`BULB3D-VENDOR` 492–1794 行、`BULB3D-DATA` 1795–2120 行）；只动手写区。

## 三、整页结构与滚动

```
（顶部导航 = 平台 newapi 原生，iframe 之外）
┌───────────────────────────────── 首屏 Hero (100vh) ─────────────────────────────────┐
│  左 2/5 品牌   ｜   中 2/5 灯泡+双轨(进动)+24卫星   ｜   右 1/5 动态 HUD 卡             │
└──────────────────────────────────────────────────────────────────────────────────────┘  ↓滚动，整屏滚走
┌───────────────────────── ① 创作搭档（AI Agent 是灵感创作搭档）─────────────────────────┐
│  标题区 + 4 个「一键生成X」大图模块（智能对话/图像/视频/Vibe Coding）                   │
└──────────────────────────────────────────────────────────────────────────────────────┘
┌───────────────────────────────── ② 我们的优势 ─────────────────────────────────────────┐
│  4 张卖点卡（智能对话 · 图像创作 · 视频生成 · 智能编程）                                 │
└──────────────────────────────────────────────────────────────────────────────────────┘
┌───────────────────────────── ③ 套餐价格（tokenplan 额度包）────────────────────────────┐
│  6 档套餐卡（Trial~Max）+ 一句机制说明                                                   │
└──────────────────────────────────────────────────────────────────────────────────────┘
（页脚 = 平台 newapi 原生，iframe 之外）
```

**滚动实现要点**：
- 解锁滚动：现有 `html,body{overflow:hidden;height:100%}` → 改为允许纵向滚动；页面高 = Hero(100vh) + 各板块自然高度。
- **深空背景延续**：`#bg`/`#grid`/星尘保持 `position:fixed` 作为**全页持久背景**（一体感），随滚动不动。
- **灯泡随首屏滚走**：把 Hero 内容（`#bulb3d` 画布、`#orbits`、`.chip`、`#halo`/`#bulb`、光线、`#hero` 文案、右栏 HUD 卡）收进一个 `<section class="hero">`（`position:relative;height:100vh;overflow:hidden`），元素由 `position:fixed` 改 `position:absolute`（相对 hero），随 hero 一起滚出。
- **性能**：Hero 滚出视口时用 `IntersectionObserver` 暂停 3D `requestAnimationFrame`（省电、防后台空转，呼应 W6 精神）。
- 下方板块：深色半透明卡 + 毛玻璃，浮在深空背景上；入场用 `IntersectionObserver` 触发一次淡入上浮。

## 四、首屏 Hero（2:2:1 灯泡场景）

> 决策 7–13 的落地。横向 `2fr:2fr:1fr`（40/40/20）浮层；画布全屏、视觉中心移到中栏 x≈60%。

- **左栏（40%，极简品牌·左对齐·垂直居中）**：徽章 `● 新一代 AI 平台` + `WeDream AI`（订正大小写+空格）+ `让灵感不再受限`（青紫渐变）+ `自由穿梭于顶尖大模型之间`。无 CTA/指标条。`#hero` 由顶部居中改到左栏、`text-align:left`、`pointer-events:none` 保留。入场 `rise` 动画加载即播一次。
- **中栏（40%，灯泡舞台）**：three.js 粒子灯泡 + 玻璃罩 + 辉光 + 点光源 + 双轨能量线 + 24 卫星 + 彗尾流光 + 光线 + 雷达环，整体居中于 x≈60%。灯泡造型保持现状（**不做圆润化**，不动点云 bin）。WebGL 不可用回退 PNG 灯泡。
  - **x≈60% 平移**：新增 CSS 变量 `--cx:60%`，把相关元素 `left:50%`→`left:var(--cx)`；JS `layout()` 里 `cx=w/2`→`cx=w*0.60`。
  - **轨道进动（伪3D）**：把每条轨道升级为「3D 环 → 绕竖(Y)轴进动 → 投影」——① 局部圆 `(R·cosφ,0,R·sinφ)`，`φ=phase+dir·2π·t/period`（沿用 40s/52s）；② 绕 X 轴倾角 `ι`（取代原 `tilt`）；③ 绕 Y 轴进动 `ψ=precessDir·2π·t/precessPeriod`（A 顺 45s / B 逆 70s，与卫星错开）；④ 投影 `x=cx+p.x·S、y=cy−p.y·S`，深度由 `p.z` 定 near/far。观感：椭圆宽窄随进动"呼吸"，像真的绕灯泡球体转。能量线（64 段×4 层）每帧重投影；**性能兜底**：1080p 掉帧则降 SEG 64→48 / 轨道线每 2 帧更一次 / PRM 时进动停相位——Playwright 实测后定。
- **右栏（20%，新增动态 HUD 卡）**：毛玻璃单卡（状态点 + 供应商 + 系列名 + 特点 + 场景 + 遥测行；左边框=品牌色）。默认 = `WeDream 核心 · 系统运行中 · 中央智能核心，环绕的卫星代表已接入的大模型，实时互联。 · 核心负载 100%`。数据取 proposal 附录 A（24 家中文）+ 附录 B（品牌色）。
- **交互（净新增）**：卫星 chip 挂 DOM 事件——悬停→右卡淡出→切该家→淡入；点击→灯泡 `setCoreColor(hex)`（点光源+辉光+着色器新增 `uEdgeColor` uniform 联动，~0.5s 渐变）；移开 1s→卡回默认、灯泡回青 `#00f0ff`。
- **去门控**：`body` 直接 `lit`；删 `#hint`「点击点亮」+ pre/lit 隐藏样式；`surge()` 迸发改接"点击卫星"。

## 五、板块① 创作搭档（AI Agent = 灵感创作搭档）

> 强调"AI Agent 不只是工具，更是你的灵感创作搭档"，偏**动作/演示大图**感。

- **标题区**：主标题「AI Agent，不只是工具，更是你的灵感创作搭档」+ 副标一句（草稿：`一句话描述，模型帮你把灵感变成作品`，可改）。
- **4 个「一键生成X」大图模块**（草稿文案，用户可逐条改）：

| 模块 | 主文案 | 说明 |
| --- | --- | --- |
| 一键智能对话 | 和 24+ 顶尖模型自由对话 | 一个入口，任意切换 |
| 一键生成图片 | 描述一句，出图即刻 | 聚合主流绘图模型 |
| 一键生成视频 | 文字 / 图片，一键成片 | 创意快速落地 |
| 一键 Vibe Coding | 说人话，写代码、造应用 | 自然语言编程 |

- **视觉/素材约定（已定）**：首期模块"大图/演示感"用**自托管内联 SVG + CSS 渐变插画**实现（沿用 proposal「无外链」，保持单文件自包含）。**用户后续会提供真实图片**，届时替换内联占位插画即可——实现时把每个模块的插画封成**独立、易替换的区块**（清晰替换点 + 注释标注），方便日后换成 `<img>`/内嵌 base64。

## 六、板块② 我们的优势

> 与①同四项能力，但偏**卖点文案卡**（"为什么选我们"）。4 张卡：

| 卡 | 标题 | 卖点草稿（可改） |
| --- | --- | --- |
| 1 | 智能对话 | 顶尖大模型任你切换，多轮上下文稳定可靠 |
| 2 | 图像创作 | 聚合主流绘图模型，风格随心、出图高清 |
| 3 | 视频生成 | 文生 / 图生视频，创意快速成片 |
| 4 | 智能编程 | 代码生成 / 补全 / 重构，开发全程提速 |

- 每卡：图标（内联 SVG）+ 标题 + 一句卖点；毛玻璃深色卡、悬停微亮。
- **①②区分**：① 偏"能做什么"（一键动作 + 大图），② 偏"凭什么选我们"（卖点 + 图标卡），避免观感重复。

## 八、视觉与实现约定

- **一体化深色风**：全页沿用首屏深空黑 + 青蓝辉光 + 毛玻璃玻璃态；三个板块与 Hero 同一套设计令牌（背景/描边/圆角/字体栈），滚动无割裂。
- **自包含**：无 Google Fonts 等外链；中文系统字体栈；插画用内联 SVG/CSS，不引外部图片（除非用户提供素材）。
- **中文优先（W5）**：所有界面文字中文，仅品牌与供应商英文名例外。
- **滚动性能与 reduced-motion**：Hero 3D 离屏暂停；`prefers-reduced-motion` 时入场直接终值、进动减弱。

## 十、验收标准（DoD）

1. 桌面 1920×1080 首屏：三栏 2:2:1；左栏品牌左对齐垂直居中；灯泡+轨道居中 x≈60%；24 卫星可辨；品牌显示 `WeDream AI`。
2. 首屏加载即完整呈现（无「点击点亮」），入场动画播一次。
3. **轨道进动肉眼可见**：两轨绕灯泡缓慢旋转（伪3D 翻转、宽窄呼吸），A 顺 B 逆 ≤70s/圈；与卫星运行叠加不合拍；1080p 无明显掉帧。
4. 悬停卫星：右卡 ≤0.5s 切该供应商中文卡片、左边框变品牌色；点击：灯泡 ~0.5s 渐变品牌色，移开 1s 回落。
5. **页面可向下滚动**：Hero 滚走后依次见 ① 创作搭档（4 模块）→ ② 优势（4 卡）→ ③ 套餐（6 档）；深空背景全程延续、无割裂；板块入场淡入。
6. Hero 滚出视口后 3D 渲染暂停（不空转）。
7. 界面文字全中文（品牌与供应商英文名除外）。
8. WebGL 禁用（`?nowebgl`）时首屏回退 PNG 灯泡、卡片与下方板块照常、无报错。
9. Chrome 控制台零报错；Playwright 验证进程零残留（W6）。

## 十一、范围外（本次不做）

- 移动端/窄屏 <1024px 适配（后续可加竖排降级）。
- 模型矩阵板块、代理/OEM、快速接入、底部 CTA（用户明确去掉）。
- 页面自带顶部导航/页脚（平台原生承担）。
- 灯泡圆润化重采样、`v2/` Vite 工程。
- 套餐真实购买闭环（本页仅展示；购买跳平台）。
- 创作板块真实产品截图/视频素材（首期用内联插画；用户提供素材再替换）。
