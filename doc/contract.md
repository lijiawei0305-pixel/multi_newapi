第六条 一期验收标准
一期验收通过需满足：
1. 真实注册 / 登录可用，管理员可真实设置代理类型。
2. *.wedreamhub.com 通配域名与 HTTPS 正常，未知站点有明确提示。
3. 用户可真实充值或购买套餐，支付成功后到账或激活套餐。
4. 重复支付回调不会重复入账、重复激活或重复分润。
5. 用户可创建 API Token，并通过真实或测试上游模型完成调用。
6. 套餐桶和钱包桶独立计量，套餐达到月度限额后可拦截，钱包余额不被错误扣减。
7. 管理端可完成套餐、子代理、提现等核心操作。
8. 代理端可完成用户组、用户、推广、兑换码、套餐上架 / 改价等核心操作。
9. 代理只能查看本租户数据，跨租户访问用户、订单、日志、收益、钱包数据必须被拒绝。
10. 灰度 24 小时无资损、无越权、无严重阻塞级故障。
