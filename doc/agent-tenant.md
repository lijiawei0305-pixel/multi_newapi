## 范围

代理商与租户的全生命周期管理：三类代理（普通 / OEM / API）的能力边界、代理等级、钱包收益、推广渠道、兑换码、下级用户管理、租户站点配置，以及超级管理员的子代理管理。

## 角色（来自 §3）

- [ ] 超级管理员：全局权限、设代理类型/成本价/分润/等级、风控与提现审核（§3.1）
- [ ] 代理商：管理下级用户、用户组倍率、兑换码、推广渠道、收益提现；OEM 配置品牌；API 代理用开放 API（§3.2）
- [ ] 终端用户：注册/充值/创建 Key/调用/查日志（§3.3）
