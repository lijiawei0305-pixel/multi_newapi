# UIUX 改造规格（对标 TOKEN HUB，基于 new-api 新版前端） — uiux.md

> **来源**：`TOKEN HUB 文档 1.md` 的 9 张真实截图 + 各部分功能解释。**关键事实**：TOKEN HUB 本身就是**定制版 new-api「新版前端」**（侧栏已含「订阅管理」= 我们的 tokenplan）。
> **目标**：在 new-api 新版前端基础上**还原这套 UIUX + 接我们的多租户后端**，并补齐截图未覆盖的 **tokenplan 页面**（按 `api-contract.md` 设计）。
> **对接**：所有数据/操作走 [`api-contract.md`](api-contract.md)；错误按其错误码注册表展示。
> **分工**：前端 CC 在 `web/`（React + Semi）按本规格实现；后端按 `api-contract.md` 提供接口；最后 playwright-cli 浏览器 E2E 验证。

---

## 1. 全局框架与设计令牌（Design Tokens）

**布局**：顶栏(~56px) + 左侧栏(~220px，角色分组) + 内容区(白底卡片，留白充足)。响应式：移动端侧栏抽屉化。

**顶栏**：`Logo + 品牌名`（按租户）｜ 导航 `主页 · Hub · 控制台 · 模型广场 · 排行榜 · 文档 · 关于 · 代理加盟` ｜ 右：`搜索(⌘K) · 🔔通知 · 🌐语言 · 🎨主题 · 头像`。

**令牌**（沿用 Semi + new-api 新版前端，按租户主题色覆盖）：
| 类 | 规格 |
| --- | --- |
| 主操作按钮 | **黑底白字**圆角（创建/保存/确认提交）；次级=描边按钮（查看/取消） |
| 状态 | 绿点 `已启用/正常`；红 `已拒绝/撤销/删除`；中性灰 `禁用` |
| 卡片 | 白底、圆角 ~12px、细边框 `#e5e7eb`、轻阴影；区块标题(图标+标题+副标题) |
| 徽章/Chip | pill 形（分组 `金牌 0.8x`、邀请渠道、类型）；浅底深字 |
| 统计卡 | 左图标 + **大号粗体数字** + 灰色标签（如 当前余额 ¥1,462.26 / 剩余配额） |
| 表格 | 表头可排序(↕)、行 hover、操作列图标按钮、底部分页(每页行数+页码) |
| 货币 | **¥** 前缀（充值/收益/售价）；**额度/计量用 USD**（与钱包桶一致，UI 标注区分，呼应 api-contract §1） |
| 主题 | 🎨 亮/暗 + 租户主题色（限主站色板，呼应 SiteConfig `THEME_NOT_IN_PALETTE`）；🌐 中/英 i18n |

**主题来源**：主站「系统设置 → 站点与品牌」可切「新版前端(默认)/经典前端」；租户主题由 `GET /api/tenant/current` 下发（Logo/品牌名/主题色/页脚）。

## 3. 逐页规格（截图还原 + 接口映射）

> 每页：**布局要点** ｜ **数据/操作接口** ｜ **改造/增量点**。

### 用户 / 通用
- **3.1 概览 / 数据看板**：顶部统计卡（余额/总用量/请求数/用量图表）＋ 趋势图。｜ `GET /api/tenant/stats` ｜ 改造：多租户范围，仅本人/本站数据。
- **3.2 API 密钥**：标题 + `创建API密钥`(黑)；筛选(名称/状态)；表格列 `名称·状态·密钥(掩码+复制)·额度·分组(金牌0.8x)·模型·IP限制·创建/最后使用时间·过期·操作(禁用/…)`；分页。｜ `GET/POST/PATCH/DELETE /api/tenant/tokens` ｜ 改造：Token 绑租户、`model_allowlist`、分组倍率显示。
- **3.3 钱包 / 充值**：3 统计卡(当前余额/总用量/API请求) ＋「添加资金」卡：金额预设(73/146/365/730/1460/3650 Pay X) + 自定义金额(实时算待支付) + 付款方式(支付宝/微信) + 兑换码框；`订单历史`。｜ `GET /api/tenant/wallet`、`POST .../wallet/recharge|redeem`、`GET .../wallet/orders` ｜ 改造：充值入账绑租户、差价计入代理；**单位 ¥**。
- **3.4 使用日志 / 任务日志**：表格(模型/输入输出 token/消耗/Key/渠道/时间)；筛选。｜ billing-logs ｜ 改造：租户隔离。
- **3.5 游乐场(Playground)**：模型选择 + 对话 + System Prompt + 参数(温度等) + 会话管理。｜ `/v1/chat/completions` ｜ 复用 new-api。

### 代理 / OEM 管理 🅖
- **3.6 品牌配置**（Tab 式）：`品牌 / 联系 / 充值 / 内容 / 首页 / 协议`；品牌 Tab = 站点名称/LOGO地址/页脚版权/自定义域名；`保存配置`(黑)。｜ `GET/PATCH /api/tenant/site-config`、`/theme-options` ｜ 改造：受控装修、主题色限色板、首页模式仅 default/config、custom_html 锁定。
- **3.7 我的用户组**：`新建分组`(黑)；分组卡(名称 `agent{id}_xxx` + 当前倍率 + 倍率输入 + 保存)；区分「我创建的分组 / 当前用户所在分组(含人数)」。｜ `GET/POST/PATCH /api/tenant/groups`、group-pricing ｜ 改造：**倍率不得低于主站保护线**（`RATIO_BELOW_FLOOR`），后端强校验。
- **3.8 我的用户**：3 统计卡(邀请用户数/用户总余额/用户总消耗)；表格列 `ID·用户名·显示名·邮箱·分组·余额·已消耗·邀请渠道(推广渠道/推广计划/代理域名)·状态·注册时间·操作(禁用/删除/改分组)`。｜ `GET /api/tenant/users`、`PATCH .../:id/status|group` ｜ 改造：归属与 `邀请渠道` 来自 Promotion。
- **3.9 兑换码**：`创建兑换码`；表格(名称/额度/数量/状态 启用·禁用·已使用/过期)；创建时从代理额度预扣。｜ `GET/POST /api/tenant/redemption-codes`、`PATCH .../:id/status`。
- **3.10 推广渠道**：`新建渠道`；渠道(名称+前缀)→ 生成 `/sign-up?channel=<prefix>_<rand>`；统计注册数。｜ `GET/POST/DELETE /api/tenant/promotion-channels`。
- **3.11 提现（钱包内）**：「提现申请」卡(提现金额[最多¥X]/收款方式/收款人/账号/备注/确认提交) ＋「申请记录」(¥·方式·状态 已通过/已拒绝) ＋「推荐计划」(待确认/总收入/邀请数/推荐链接/转移到余额)。｜ `POST/GET /api/tenant/withdrawals`、earning-logs ｜ 改造：冻结→审核→打款；收益 ¥。

### 管理员 🅐
- **3.12 渠道**：标签模式/ID排序开关、`创建渠道`；筛选(名称/模型/状态/类型/分组)；表格(ID/名称/类型/状态/分组/优先级/权重/已用·剩余/响应/上次测试/测试·禁用·…)。｜ admin 渠道 ｜ 复用 new-api。
- **3.13 模型 / 用户 / 兑换码（管理员）**：复用 new-api 原生表格 + 多租户维度。
- **3.14 ★订阅管理（tokenplan）**：见 §5（截图未覆盖，按 api-contract 设计）。
- **3.15 子代理管理**：`选择用户设为代理`(搜索+设为代理[黑]/行)；下方现有代理列表(用户名/邮箱/自定义域名/状态 代理/撤销[红])；右上 `提现管理`。｜ `POST /api/admin/agents`、enable/disable、domains ｜ 改造：设类型(普通/OEM/API)+成本价/折扣/分润/等级。
- **3.16 推广渠道（管理员）/ 提现审核**：全站渠道；提现 `approve/reject`。｜ admin/withdrawals。
- **3.17 系统设置**：结构化左子导航 `站点与品牌(系统信息/系统公告/顶部导航/侧边栏模块) · 身份验证 · 计费与支付 · 模型与路由 · 安全与限制 · 控制台内容 · 运维`；系统信息=前端主题切换/系统名称/站点描述/服务器地址/徽标/页脚/关于。｜ 系统配置接口 ｜ 改造：新增 tokenplan 计费参数、保护线、限购配置入口。

## 4. tokenplan ★ 新页设计（截图未覆盖，按 api-contract §2.4 设计，沿用上面令牌）

> 这是我们相对 TOKEN HUB 的核心增量；UIUX 必须与上面风格一致（Semi 卡片/黑按钮/¥）。

- **4.1 套餐购买页（用户，前台/控制台）**：响应式**套餐卡片网格**（Trial/Mini/Solo/Lite/Pro/Max）。每卡：套餐名 + **¥售价(大号)** + `anchor_price` 划线原价 + `discount_label` 角标(-91%) + 月限额($USD) + 倍率 x1 + `is_recommended/badge` 热门角标 + `购买`(黑)。｜ `GET /api/tenant/token-plans`、`POST .../:id/purchase` ｜ Trial 失败 `PURCHASE_LIMIT_EXCEEDED` → "每人限购一次"提示。
- **4.2 我的套餐**：当前订阅卡(套餐名/状态 active·exhausted·expired/进度条 `used_usd/month_limit_usd`/剩余/到期日)；用尽/到期 → 醒目「重购」（**不自动用钱包**，呼应独立计量）。｜ `GET /api/tenant/subscriptions`。
- **4.3 代理上架/改价（OEM 管理新增项）**：套餐列表(开关 上架/退出 + 零售价输入)；保存校验 `retail≥min_price`(`RETAIL_BELOW_MIN` → "低于套餐保护价")。｜ `GET/PATCH /api/tenant/token-plans/manage`。
- **4.4 订阅管理（管理员，侧栏已有项）**：套餐 CRUD 表格(code/名称/售价/原价/月限额/成本价/保护线/排序/状态) + 编辑抽屉；另一 Tab「订阅监控」表格(用户/套餐/used·limit/进度/状态) + **满额逼近预警**高亮(≥80%，呼应防巨亏)。｜ `GET/POST/PATCH /api/admin/token-plans`、`GET /api/admin/subscriptions`。

## 5. 复用 vs 改造/新建（前端工作量边界）

| 类别 | 页面 |
| --- | --- |
| **复用 new-api 新版前端**（接多租户数据即可） | 概览/数据看板、API 密钥、使用/任务日志、游乐场、渠道、模型、用户（管理员）、系统设置框架 |
| **改造**（多租户/品牌/保护线） | 钱包充值(预设+兑换+绑租户)、我的用户组(保护线)、兑换码、系统设置(加 tokenplan/保护线/限购项) |
| **新建/重点**（我们的增量） | **OEM 管理整组**(品牌配置 tabs/我的用户/推广渠道/提现+推荐计划)、**子代理管理**、**tokenplan 全套**(购买页/我的套餐/代理上架/订阅管理)、多租户换肤 |

## 6. 前端对接清单（交给前端 CC）

1. 按 §2 侧栏 IA + §3/§4 逐页规格 + §1 令牌实现；数据/错误全部走 [`api-contract.md`](api-contract.md)。
2. **错误处理**：读 `code` 映射文案（api-contract §1.1），勿仅 `message`。
3. **单位**：充值/收益/售价 ¥；额度/计量 USD；勿混算。
4. **多租户换肤**：`GET /api/tenant/current` 下发品牌/主题；未配置回退主站默认；主题色限色板。
5. **tokenplan**：营销字段(划线价/折扣角标/推荐)、双桶提示(套餐 vs 钱包)、Trial 限购提示、满额预警(管理员)。
6. **一期风格**：先 new-api 新版前端原样；二期再按 superpowers UIUX 模型品牌化升级。
7. **验证**：联调用 **playwright-cli** 跑 注册→开站→配置→购套餐→调用→看板 端到端，对照本规格 + api-contract。
