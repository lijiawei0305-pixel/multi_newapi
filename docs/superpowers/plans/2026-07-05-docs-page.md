# 文档页 `/docs` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个公开、免登录的 `/docs` 页面，忠实克隆 tokenhub `/docs` 的头部+四段结构（快速开始 / 接入步骤 / 示例代码 / 联系支持），内容替换为本项目，并让页眉「文档」链接指向它。

**Architecture:** 两个新文件（TanStack Router 路由外壳 + `features/docs` 页面组件），复用 `PublicLayout` + `PublicHeader` + `Footer` + shadcn `Card`；示例域名用 `window.location.origin` 动态注入（多租户下代理站显示自己域名）。外加一处页眉导航微调，使内部 `/docs` 成为默认「文档」目标（仍保留 OEM 自定义外链能力）。

**Tech Stack:** React 19 · TanStack Router（文件路由，`routeTree.gen.ts` 自动重生）· Tailwind v4 · shadcn/ui · i18next · sonner（toast）· lucide-react。

## Global Constraints

### Task 3: 页眉「文档」指向内部 `/docs`

**Files:**
- Modify: `web/default/src/hooks/use-top-nav-links.ts`（Docs 分支，约 line 97–106）

**Interfaces:**
- Consumes: 现有 `docsLink`（来自 `status.docs_link`）、`t('Docs')`（已存在，中文「文档」）。
- Produces: 页眉「文档」项默认 `href: '/docs'`（内部），仅当管理员设置了**非上游默认**的自定义外链时才走外链。

> **背景（实测）**：`docs_link` 后端默认非空（`https://docs.newapi.pro`），若不改，页眉「文档」会指向该外链而非我们的 `/docs`。此改动让内部页成为默认，同时保留 OEM 自定义外部文档能力。

- [ ] **Step 1: 定位现有分支**

Run: `grep -n "modules?.docs" web/default/src/hooks/use-top-nav-links.ts`
读取该分支现状，应形如：

```ts
if (modules?.docs !== false) {
  if (docsLink) {
    links.push({ title: t('Docs'), href: docsLink, external: true })
  } else {
    links.push({ title: t('Docs'), href: '/docs' })
  }
}
```

- [ ] **Step 2: 改为「内部优先，仅自定义外链才走外部」**

将上述分支替换为：

```ts
if (modules?.docs !== false) {
  // 平台已有第一方 /docs 文档页 → 内部页为默认；
  // 仅当管理员设置了非上游默认的自定义外链时才跳外部（保留 OEM 能力）。
  const UPSTREAM_DEFAULT_DOCS = 'https://docs.newapi.pro'
  if (docsLink && docsLink !== UPSTREAM_DEFAULT_DOCS) {
    links.push({ title: t('Docs'), href: docsLink, external: true })
  } else {
    links.push({ title: t('Docs'), href: '/docs' })
  }
}
```

- [ ] **Step 3: 类型检查**

Run: `bun run typecheck`
Expected: 退出码 0。

- [ ] **Step 4: 提交**

```bash
git add web/default/src/hooks/use-top-nav-links.ts
git commit -m "feat(docs): 页眉「文档」默认指向内部 /docs(保留 OEM 自定义外链)"
```
