# bulb-orbit 粒子灯泡替换设计（定稿）

> 日期：2026-07-07 ｜ 状态：用户已逐节确认（互动式提问定稿）
> 目标文件：`bulb-orbit/index.html`（唯一成品）｜ 素材来源：GitHub `wei500L/yun`（本地克隆于 scratchpad，提交 `a496af7`）

---

## 1. 背景与目标

`bulb-orbit/index.html` 是零依赖单文件视觉页：PNG 玻璃灯泡 + CSS 光晕居中，24 个模型 logo 芯片沿 2 条 2D SVG 椭圆轨道环绕，顶部中文文案「Wedream AI / 让灵感不再受限」，两段式点击点亮交互（`body.pre` 只亮灯泡 → 点击 `body.lit` 全景，2026-07-06 定稿，见 `bulb-orbit/交互修改文档.md`）。

`wei500L/yun` 是 Vite + Three.js 项目，其灯泡形象为 **WebGL 粒子点云**：40000 粒子按 `dengpao.glb`（82MB）预采样坐标+法线（`public/models/dengpao_points.bin`，938KB）排布成灯泡形状，自定义 shader 驱动动效，外围程序化玻璃罩/金属灯座/发光灯丝/体积辉光，整帧过 UnrealBloom 泛光，配色青蓝 `#00f0ff`。

**本次目标：只把 yun 的粒子灯泡形象（含全部动效）替换进 bulb-orbit，替掉 PNG 灯泡；其余一切保留。**

## 2. 需求结论（逐问定稿）

| 决策点 | 结论 |
| --- | --- |
| 替换范围 | 只换灯泡本体；我们的 2D 轨道、24 logo 芯片、中文文案、两段式交互全保留。**不**引入 yun 的 3D 轨道 / 11 卫星 / HUD / 页面框架 |
| 用途与打开方式 | 双击即开优先（可离线），结构上便于日后上线 |
| 实现形态 | **A 全内嵌单文件**（three.js + Bloom 后期 + 点云 base64 全内嵌，成品约 2.5MB）；点云另存独立 `.bin` 备用 |
| 交互动效 | 基础动效全移植 + **鼠标排斥流体** + **点击核心喷发**；**不要**拖转视角（弃 OrbitControls） |
| 配色 | 保持 yun 青蓝原样（现页面本就是蓝青调，天然同源，无需改造） |
| 降级 | WebGL 不可用回退现有 `bulb.png` + CSS 光晕 |

## 3. 方案选择记录

- **选定 A・全内嵌单文件**：视觉 100% 还原（含 Bloom）；双击即开、离线可用；发人/上线都是一个文件。
- 弃 B（文件夹形态：index.html + vendor + data 经典脚本）：三文件必须同行，单发 index.html 白屏。
- 弃 C（无 Bloom 轻量版）：泛光柔度打折（约 85–90% 还原），与「形象忠实替换」的目标冲突。

## 4. 架构设计

### 4.1 分层

全屏**透明 WebGL 画布**插入现有 DOM 层级，替代原 `#halo`（CSS 光晕）+ `#bulb`（PNG）所在层：背景 `#bg`/`#grid`/轨道 `#orbits` 在画布后；`#hero` 文案、`#hint` 提示、`#vignette` 在画布前；`.chip`×24 保持原 z-index 2..10 体系**穿越**画布层（画布 z:6，近侧芯片过前、远侧过后，透明合成下遮挡关系与原 PNG 等价——2026-07-07 终审修正措辞）。

- 画布 `pointer-events:none`：现有点击点亮、芯片悬停零干扰；灯泡所需鼠标事件（排斥、点击喷发）监听 `window` 坐标换算，不经画布。
- 相机固定（无控制器）；灯泡投影位置/大小**精确对齐原 PNG 屏幕占位**（水平居中、垂直中心 `--cy` 57%、同等身量），保证轨道与芯片的环绕关系不变。
- 原 `#bulb`/`#halo` 保留在 DOM 中默认隐藏，作降级回退。

### 4.2 透明画布 × Bloom 的合成

UnrealBloom 与透明画布有已知黑底冲突。解法：后期管线末尾追加一个「**亮度转 alpha**」微型 ShaderPass（`alpha = clamp(max(r,g,b))`）。页面为深色底（`#020610`），该合成与加法发光视觉等效，泛光柔度不打折。管线：RenderPass → UnrealBloomPass(0.6/0.45/0.85) → OutputPass → AlphaFromLuma。

## 5. 灯泡装配移植清单（照搬 yun 参数与 shader）

| 部件 | 内容 |
| --- | --- |
| 粒子点云 | 40000 粒子（`dengpao_points.bin` 坐标+法线+每粒子随机数）；顶点/片元 shader 完整移植：法线呼吸(±0.006 世界单位)、微噪声抖动、整体呼吸脉冲(±1.2%)、每粒子闪烁、径向色渐变（核心亮白蓝→边缘青蓝）、鼠标排斥场（高斯衰减、推开成环、缓入快/缓出慢回流） |
| 玻璃罩 | 程序化穹顶(r0.36)+瓶颈，Phong 半透明 opacity 0.05 |
| 灯座/灯丝 | ~~金属灯座圆柱 + 白色发光灯丝小圆柱~~ + 青色点光源 + 深蓝环境光（修正 2026-07-07：灯座与灯丝按用户反馈移除——灯丝呈白色光条、暗色灯座写深度+亮度转alpha 在点云底座冲出黑框；点云自带底座形状） |
| 体积辉光 | Canvas 径向渐变辉光 sprite（替代原 CSS `#halo`） |
| 自旋 | 点云+装配组 `rotation.y` 匀速自转（0.02 rad/s） |
| Bloom | UnrealBloom 强度 0.6 / 半径 0.45 / 阈值 0.85；ACESFilmic 色调映射 |
| 不带 | 雾效（页面自有背景）、OrbitControls（不拖转）、GSAP（喷发用原生缓动）、yun 的轨道/卫星/HUD/页面框架 |

## 6. 交互整合（两段式状态机不动）

| 时刻 | 行为 |
| --- | --- |
| `pre` 初始黑场 | 粒子灯泡带全部基础动效独自发光；鼠标排斥已生效；「点 击 点 亮」提示不变 |
| 点击点亮瞬间 | 原 CSS `igniteBurst` 改由 3D **核心喷发**承担：辉光增亮 + 点光源闪烁一次（灯丝脉冲随灯丝移除，2026-07-07）；2D 点亮时间轴（轨道渐显/芯片逐个浮现/文字升起）完全不变 |
| `lit` 常驻 | 再点击灯泡本体区域（屏幕坐标命中判定，非 raycast 40k 点）→ 重放核心喷发；点其他处无反应 |
| `#final` 直达 | 灯泡直接常驻态，跳过喷发（截图/海报模式） |
| `prefers-reduced-motion` | 粒子时间冻结为静态发光灯泡；排斥/喷发停用 |

## 7. 文件结构与构建

```
bulb-orbit/
├── index.html                  ← 唯一成品（~2.5MB）：①页面区(现有代码,日常改这里)
│                                  ②vendor区(three.module.min.js r160+Bloom后期模块拼接,勿手改)
│                                  ③数据区(dengpao_points.bin base64,勿手改) ④灯泡区(3D装配代码)
├── assets/dengpao_points.bin   ← 独立点云备份（日后上线改 fetch 时直接可用）
├── tools/build-single.py       ← 单文件拼装脚本（重生 vendor/数据区块，可复现）
├── tools/vendor-src/           ← three r160 官方源文件（CDN 下载一次留存）
├── bulb.png                    ← 保留作回退形象
└── 交互修改文档.md + 两张阶段截图 ← 完成后更新/重截
```

拼接方式：inline `<script type="module">`（`file://` 下内联模块可运行、无 CORS）；three 与后期模块去 import/export 后按依赖序拼接，我方代码殿后。

## 8. 降级与性能

1. WebGL 初始化失败/不支持 → `body.no-webgl`：隐藏画布，显现保留的 `bulb.png` + 原 CSS 光晕，页面回到 2026-07-06 版观感，两段式交互照常。
2. `prefers-reduced-motion` → 见 §6。
3. 性能：DPR 上限 2（yun 原设定）；后台标签 rAF 自动暂停；40000 粒子 + Bloom 在普通 Mac 核显无压力。
